## Исправления

| Дефект | Воспроизведение | Исправление |
|---|---|---|
| `write_json` выбрасывал `UnicodeEncodeError` | Структурное значение или JSON-строка с непарным `\ud83d` | Контролируемый `ToolResult(ok=False)` до открытия файла, прежние байты сохранены |
| `write_json` сообщал успех для невалидного JSON | Вложенный `NaN`, `Infinity`, `-Infinity`, включая строковое представление | `allow_nan=False`, отказ до записи |
| `replace_text` пропускал неоднозначные перекрывающиеся якоря | `aaa` с якорем `aa`, `ababa` с `aba` | Поиск первого и второго совпадений со сдвигом на один символ, отказ без изменения файла |
| Сборщик включал посторонние файлы и содержимое внешних симлинков | `.env`, ключи, бинарные файлы, скрытые `.py`, `venv`, симлинк `agent/main.py` | Разрешены только обычные Python-исходники вне исключённых каталогов; симлинки отбираемых источников отвергаются до открытия zip |
