# Журнал инженерных решений

Формат: дата, статус, решение, основание, последствия. Статусы:
`принято`, `гипотеза`, `отменено`.

| Дата | Статус | Решение | Основание и последствия |
|---|---|---|---|
| 2026-08-24 | принято | Оптимизировать в порядке solved count → tokens → wall time | Это официальный порядок ранжирования; экономия не может оправдать регрессию решаемости |
| 2026-08-24 | принято | Public tasks использовать как contract/regression набор, но не как перечень закрытых задач | Организаторы прямо говорят, что финальный benchmark закрытый и другой; production-код не содержит их имён/ответов |
| 2026-08-24 | принято | Проверять фактически собранный и распакованный zip в offline target image | Ошибка упаковки даёт ноль независимо от качества агента |
| 2026-08-24 | гипотеза | Начать с одного bounded tool loop и playbooks вместо нескольких LLM-агентов | Меньше calls/context loss; подтвердить baseline и абляцией |
| 2026-08-24 | принято | Любое завершение требует внешнего verifier, когда oracle доступен | Self-report малой LLM не доказывает прохождение автоматической проверки |
| 2026-08-24 | принято | Не фиксировать tag/digest `secureintelligent/acp` до локальной проверки | В ТЗ дано имя образа, публичные страницы могут обновляться; submission должен ссылаться на реально испытанный digest |
| 2026-08-24 | принято | `CLAUDE.md` — канонические полные правила; `AGENTS.md` требует прочитать его | Команда работает разными coding agents, а дублирование полного набора правил быстро расходится |
| 2026-08-24 | принято | Целевая стратегия — deterministic preflight/budget guard + один universal LLM-loop + verifier/recovery | Взвешенный аудит пяти вариантов дал 4,23/5; направление проверяется gates G1–G6, параметры не фиксируются без baseline |
| 2026-08-24 | принято | В public наборе шесть task packages, `insecure-api-app` — fixture | Подтверждено наличием шести `task.toml` на upstream `71f9081`; исправлена прежняя оценка «семь задач» |
| 2026-08-24 | принято | Public baseline не считается offline-тестом | В public task configs стоит `allow_internet = true`, а финальный регламент требует microVM без сети; нужен отдельный network-disabled gate |
| 2026-08-24 | гипотеза | Submission zip должен иметь `run.sh` в корне | README указывает это, но sample archive обёрнут каталогом `sample_submission/`; решение примет только Harbor smoke/ответ организаторов |
| 2026-08-24 | принято | Шансы оценивать уровнями R0–R5, а не выдуманным процентом | До target-model baseline и закрытой КТ неизвестны budgets, сложность и конкуренты; текущий уровень R0 |
| 2026-08-25 | принято | Границы задаются `typing.Protocol` + `dataclass`, в `agent/` только stdlib | Установка зависимостей на прогоне запрещена, наличие SDK в образе не подтверждено; проверяется обходом AST в CI |
| 2026-08-25 | принято | Провал вызова модели — типизированный `LlmError`, а не исключение | Малая модель регулярно отдаёт непарсящийся вывод; исключение превращает один кривой ответ в ноль по задаче |
| 2026-08-25 | принято | Стартовый уровень протокола — константа из измерения; runtime-probe отменён | Модель одна на всех 15 задачах, probe на каждом прогоне платит токенами за один и тот же ответ. Измеряет `scripts/probe_endpoint.py`, страхует ленивая липкая деградация |
| 2026-08-25 | принято | Непарсящийся ответ не переспрашивается при том же уровне протокола | При `temperature=0` повторный запрос байт-идентичен и даёт тот же ответ; понижение уровня — да, повтор — нет |
| 2026-08-25 | принято | Токены без `usage` от endpoint помечаются как незамеренные, а не оцениваются | Токены — второй критерий ранжирования; выдуманная оценка хуже отсутствующей |
