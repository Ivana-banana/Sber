# Sber × AIRI — Universal Cybersecurity Agent

Репозиторий решения соревнования AIRI по созданию универсального автономного
ИБ-агента для малой локальной LLM в изолированном контуре.

Агент должен получить текст задачи, исследовать доступное локальное окружение,
выполнить необходимые действия и довести задачу до результата, который принимает
автоматическая проверка. Интернет во время оценки недоступен, зависимости нельзя
доустанавливать, а итоговый архив должен весить не более 10 МБ.

При расхождении источников приоритет такой: актуальные правила на платформе
организаторов → публичный репозиторий организаторов → `Тз сбер.docx` → наши планы.
Расхождение сначала записывается в `docs/decisions.md`, затем исправляется код.

`Тз сбер.docx` — неизменяемый первоисточник, он хранится для разбора спорных
формулировок. В работе читается `docs/task.md`: там же указаны checksum оригинала
и команда сверки. Распаковывать `.docx` при обычной работе не нужно.

## Текущее состояние

Реализованы runtime в `agent/`, локальные инструменты, LLM-клиент, цикл выполнения
и проверка результата. В репозитории есть публичные задачи, дополнительные
фикстуры, тесты и инструменты сборки submission. Актуальный кандидат, незавершённые
работы и результаты замеров указаны в `HANDOFF.md`, последних разделах `PLAN.md`
и `docs/experiments.md`; отдельные рабочие копии могут содержать разные версии кода.

Локальная проверка и сборка:

```sh
python3 -m pytest -q
python3 scripts/build_submission.py --out build/submission.zip
python3 scripts/check_submission.py build/submission.zip
```

Сборщик включает `run.sh`, `THIRD_PARTY_NOTICES.md` и Python-исходники `agent/`.
Скрытые каталоги, виртуальные окружения и файлы других типов не включаются;
симлинки в отбираемых исходниках приводят к отказу сборки. Новые runtime-ресурсы
других типов требуют явного расширения allowlist и теста упаковки.
