# HANDOFF.md — доска текущей работы

Этот файл отвечает только на вопросы «кто делает сейчас», «что нельзя трогать» и
«как принять результат». История и стратегия находятся в Git и `PLAN.md`.

## Правила

- Перед нетривиальной задачей участник добавляет одну строку в активные задачи.
- Один файл/контракт одновременно имеет одного владельца.
- При завершении указать commit, проверку и известные ограничения, затем перенести
  строку в «Завершено».
- Если работа ведётся локально и ещё не запушена, это писать явно.
